# Baseline noise setup

The baseline inputs and native NoiseModelling 6.0.0 workflow are prepared for
the same study area as V1 and V2. **The full study-area baseline run is pending;
its results will be added in a separate PR.** The earlier small pilot is not a
final baseline comparison.

## Inputs

Under `data/processed/noise/baseline/`, import:

- `buildings.geojson` as `BUILDINGS`;
- `ground.geojson.gz` as `GROUND`;
- `terrain.geojson.gz` as `DEM`.

The existing `ground.gpkg` and `terrain.tif` remain preparation sources.
Ground partitions preserve coverage and material attributes; `SOURCE_PK`
identifies the original record. Terrain points retain raster cell centres and
elevations, including the 900 m margin around the shared receiver boundary.

Use the common `data/processed/noise/assessment_area.geojson` as
`ASSESSMENT_AREA` and `data/processed/noise/roads/roads.geojson` as `ROADS`.
The committed road file is the same prepared input used for V1/V2; no raw
RVMK download is needed to run this workflow.
Retrieve large ground files with `git lfs pull` before importing.

## Run and export

Open [workflow.json](workflow.json) in NoiseModelling Builder with the server's
Java working directory set to the repository root. The workflow uses V1's
native setup with baseline input/output paths; its saved thread count is 6.
Receivers and triangles are generated by the native Delaunay Grid block.

Before exporting, create the baseline output directory from the repository root:

```bash
mkdir -p outputs/data/noise/baseline
```

Run the imports, road emissions, Delaunay Grid, propagation and exports in the
order documented in the [noise workflow README](../README.md#rerun-a-scenario-in-noisemodelling).
Export receiver levels before changing scenario tables. Export paths must be:

```text
outputs/data/noise/baseline/receiver_levels.geojson
outputs/data/noise/baseline/noise_map.geojson
```

The current visualization script accepts V1 and V2 only. Add baseline support
when the baseline results are introduced; no baseline figures are claimed here.
