# Baseline noise setup

Prepared baseline imports for the same assessment area as V1 and V2.
Use the existing baseline buildings.geojson and the prepared ground.geojson.gz
and terrain.geojson.gz files. Ground GeoPackage and terrain TIFF remain unchanged.
Ground partitions retain source attributes and coverage; SOURCE_PK records the
original ground record. Terrain points retain raster cell centres and elevations.

The workflow copies V1's final native NoiseModelling settings with baseline
input/output paths. Receivers and triangles are generated by Delaunay Grid
inside NoiseModelling. Launch the server from the repository root and provide
the same local roads input used for V1/V2.

Baseline simulation results are not included in this preparation commit;
they will be added in a separate PR after the run.
